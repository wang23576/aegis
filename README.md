# Aegis

> 企业智能体治理平台 —— 面向组织，支持管理员集中治理智能体、普通用户自助注册与使用。

## 状态

**骨架期**：当前仅建立项目协作规范与门面文档，功能待逐步完善。技术选型尚未确定（见 [AGENT.md](AGENT.md) §5）。

## 定位

提供一个可控、可审计、可扩展的通用智能体平台：

- **管理员**：集中管理智能体与平台资源（智能体生命周期、用户与角色、模型/工具/知识库配置、审计与监控）。
- **普通用户**：自助注册与登录，浏览并调用智能体，管理自己的会话与配置。

## 协作方式

在本仓库工作的 AI 编码助手与维护者，请先阅读并遵守 [AGENT.md](AGENT.md)（协作原则、工程约定、待决策清单、参考依据）。
